# Number_Guessing_Game
Python code to create a simple number guessing game providing hints along the way.
It involves the user trying to guess a random integer between 1 and 100. If the guess is incorrect, it provides a hint of 'higher' or 'lower'.
A tally is also in place to count the number of guesses used.
